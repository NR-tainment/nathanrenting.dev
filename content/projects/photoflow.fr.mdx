## Ce que le photographe fait encore

Trois étapes :

1. Prendre la photo
2. Retoucher la photo dans Lightroom
3. Valider

Tout ce qu'il y a entre les deux — légendes, hashtags, planification, publication vers
IG / FB / LinkedIn, blog, portfolio — c'est l'IA qui s'en charge.

<ChalkDoodle type="asterisk" className="mt-12 mb-2 opacity-50" />

## Concepts clés

**Le Projet / Shooting est l'objet principal.** Pas les &quot;posts&quot;. Un
projet (&quot;Mariage Lisa &amp; Mark&quot;) est traduit par l'IA en
plusieurs déclinaisons. Une seule validation → tous les livrables prêts.

**Curation vs Technical QA.** L'IA réalise uniquement l'évaluation technique
objective : netteté, yeux ouverts, exposition, flou de bougé. La sélection
artistique reste entièrement au photographe via les notes Lightroom.

**UX toggle-first.** Toutes les fonctionnalités sont configurées une fois pendant l'onboarding
(quatre écrans), puis uniquement via les Settings. Valeurs par défaut agressivement ON.
Le workflow n'ajoute jamais d'étapes à ce dont le photographe a déjà l'habitude.

**RAW-blind.** PhotoFlow ne lit pas le RAW. Lightroom effectue le rendu ; PhotoFlow
opère sur les previews et les exports. Fonctionne pour Canon, Fuji et toutes les marques
prises en charge par Lightroom, sans traitement particulier.

## Architecture

Configuration hybride :

| Composant | Tech | Responsabilité |
|---|---|---|
| Client desktop | Tauri + React + SQLite | En local : photos, projets, brouillons, paramètres |
| Plugin Lightroom | Lua (`.lrplugin`) | &quot;Send to PhotoFlow&quot; — communique avec le client desktop via localhost |
| Composant cloud | Supabase ou Cloudflare Workers + D1 + R2 | Proxy OAuth, rafraîchissement de tokens, file d'attente de publication planifiée, endpoints App Review |

Le choix du local-first garde les données photo hors du stockage cloud tant que
ce n'est pas nécessaire. Le cloud ne fait que ce qu'il doit faire : l'OAuth des
réseaux sociaux et la planification de publication à un moment où l'appareil du
photographe est peut-être éteint.

## Multi-agent

| Agent | Fonction |
|---|---|
| Vision | Analyse d'image, détection du sujet, ambiance |
| Copy | Légendes, hashtags, SEO, blog |
| Publishing | Planification, publication, contrôle de statut |
| Analytics | Résultats, rapports, conseils d'amélioration |

Quatre rôles, un coordinateur. Le schéma derrière une grande partie d'
ECHO se retrouve ici : une fine couche de routage répartit le travail et la
sortie atterrit dans un seul endroit structuré.

## Public cible + réalité de l'API

Les photographes professionnels avec :

- Un workflow Adobe Lightroom Classic
- Un compte Instagram Business ou Creator (obligatoire, une limitation
  technique de l'API Meta)
- Une Facebook Page
- En option : LinkedIn (personnel ou Company Page)

PhotoFlow ne prend **pas** en charge les comptes de réseaux sociaux personnels.
Ce n'est pas un choix mais une limitation stricte de l'API de Meta et LinkedIn. Mieux vaut
le dire clairement que de le découvrir pendant l'onboarding.
