# AudioLaunch — mobiele muziekstudio + Resonara

<MarkerHighlight>Een mobiele muziekstudio met een eigen native Rust audio-engine, plus Resonara: een gamified wereld waarin je sound design leert terwijl je speelt.</MarkerHighlight>{" "}
Acht jaar solo gebouwd — vanaf het eerste concept in 2018 tot de
publieke open beta van nu. Tot voor kort stond dit hier onder Stealth;
inmiddels is de naam eraf.

<ChalkDoodle type="x-mark" className="mt-12 mb-2 opacity-50" />

## Twee kanten

**Studio** is de serieuze kant: multi-track recording tot 24-bit/96kHz,
live editing, FX-chain, MIDI, sample-import, synths, mixer,
master-chain. Draait op een eigen native Rust audio-engine voor
low-latency real-time DSP op Android (NDK + JNI + React Native FFI).

**Resonara** is de andere kant: een verhaal-gedreven wereld die sound
design aanleert via missies. Vibes, werelden, level-pacing, missies en
skills als progressie-mechanieken — het spel is het curriculum.

## Status

Live in publieke open beta op [audio-launch.com](https://audio-launch.com) —
speel in de browser of pak de Android-build. Nog niet in de reguliere
Play Store-listing; dat is de volgende stap. Build-filosofie:
SOTA-or-cut — features die niet op SOTA-niveau kunnen shippen worden
uit v1.0 geknipt in plaats van halfbakken uitgebracht.

Zusterproject: [audiolab.tools](https://audiolab.tools), een publieke
browser-side audio-toolkit — apart product, ook van mij.
