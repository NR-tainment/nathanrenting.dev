# AudioLaunch — studio de musique mobile + Resonara

<MarkerHighlight>Un studio de musique mobile avec un moteur audio Rust natif maison, et Resonara : un monde gamifié qui enseigne le sound design en jouant.</MarkerHighlight>{" "}
Construit en solo depuis huit ans — du premier concept en 2018 à
l'open beta publique d'aujourd'hui. Jusqu'à récemment, ce projet
figurait ici sous Stealth ; le nom n'est plus caché.

<ChalkDoodle type="x-mark" className="mt-12 mb-2 opacity-50" />

## Deux facettes

**Studio** est le côté sérieux : enregistrement multipiste jusqu'à
24-bit/96kHz, édition en direct, chaîne d'effets, MIDI, import
d'échantillons, synthés, mixette, chaîne de mastering. Tourne sur un
moteur audio Rust natif maison pour du DSP temps réel low-latency sur
Android (NDK + JNI + React Native FFI).

**Resonara** est l'autre facette : un monde narratif qui enseigne le
sound design à travers des missions. Vibes, mondes, rythme de
progression, missions et compétences comme mécaniques de progression
— le jeu est le programme.

<ChalkDoodle type="arrow-curve" className="mt-12 mb-2 opacity-50" />

| Année | Phase |

## Statut

En ligne en open beta publique sur [audio-launch.com](https://audio-launch.com)
— jouable dans le navigateur ou via le build Android. Pas encore
présent dans la fiche Play Store classique ; c'est la prochaine étape.
Philosophie de build : SOTA-or-cut — les fonctionnalités qui ne
peuvent pas atteindre un niveau SOTA sont coupées de la v1.0 plutôt
que livrées à moitié finies.

Projet frère : [audiolab.tools](https://audiolab.tools), une boîte à
outils audio publique côté navigateur — un produit séparé, également
signé par moi.
