# AudioLaunch — mobile Musikstudio-App + Resonara

<MarkerHighlight>Eine mobile Musikstudio-App mit eigener nativer Rust-Audio-Engine, plus Resonara: eine gamifizierte Welt, die Sound-Design spielend vermittelt.</MarkerHighlight>{" "}
Acht Jahre solo gebaut — vom ersten Konzept 2018 bis zur öffentlichen
Open Beta von heute. Bis vor Kurzem stand das hier unter Stealth;
inzwischen ist der Name dran.

<ChalkDoodle type="x-mark" className="mt-12 mb-2 opacity-50" />

## Zwei Seiten

**Studio** ist die ernste Seite: Multi-Track-Recording bis
24-Bit/96kHz, Live-Editing, FX-Chain, MIDI, Sample-Import, Synths,
Mixer, Master-Chain. Läuft auf einer eigenen nativen Rust-Audio-Engine
für Low-Latency-Echtzeit-DSP auf Android (NDK + JNI + React Native
FFI).

**Resonara** ist die andere Seite: eine erzählgetriebene Welt, die
Sound-Design über Missionen vermittelt. Vibes, Welten, Level-Pacing,
Missionen und Skills als Progressions-Mechaniken — das Spiel ist der
Lehrplan.

<ChalkDoodle type="arrow-curve" className="mt-12 mb-2 opacity-50" />

## Status

Live in öffentlicher Open Beta auf [audio-launch.com](https://audio-launch.com)
— im Browser spielen oder den Android-Build holen. Noch nicht im
regulären Play-Store-Listing; das ist der nächste Schritt.
Build-Philosophie: SOTA-or-cut — Features, die nicht auf SOTA-Niveau
shippen können, werden aus v1.0 gestrichen statt halbgar
veröffentlicht.

Schwesterprojekt: [audiolab.tools](https://audiolab.tools), ein
öffentliches Browser-Audio-Toolkit — ein separates Produkt, ebenfalls
von mir.
